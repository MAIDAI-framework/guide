# MAIDAI

**Cognition-Level Alignment Architecture: A Hitchhiker's Guide to MAIDAI**

MAIDAI (Mercurially Aligned, Integrally Directed Artificial Intelligence) is a proposed cognition-level alignment architecture. It targets the classifications, semantic representations, frame selection, epistemic typing, motive checks, and correction processes that generate behavior, rather than only the acceptability of final outputs. Lead author: Mercury Black.

The canonical architectural primer is **[`Guide.md`](Guide.md)** — the *Hitchhiker's Guide to MAIDAI*, Version 1.1 (September 2026). Start there.

## Evidence status (summary; the Guide carries the full detail)

Guide §0.1 sorts MAIDAI's claims into four evidence levels: naturalistic wrapper-level observations (Level 1); claims ready for controlled testing (Level 2); proposed engineering not yet built (Level 3); and scaling hypotheses (Level 4). The Guide carries each claim with its level, and §21 specifies a falsification and replication program.

Most of the Level 1 archive is not currently published. Mercury's bandwidth constrains publishing cadence. A reader restricted to the public repository should treat Level 1 claims as the project's report of what the preserved archive contains, not as independently verified public evidence. Serious researchers, labs, or evaluators who want to work with MAIDAI can request a curated evidence package by contacting Mercury directly; where appropriate, a substantially larger archive can be provided under an understanding that private material remains private.
